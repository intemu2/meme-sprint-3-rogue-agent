# Meme Sprint 3: AI Agent Goes Rogue — "THE HUMAN"

A pure-stdlib Python program that renders one movie-poster meme to
`/output/entry.png`: an AI agent has gone rogue by making a film about its
human's life — starring itself, with the human demoted to uncredited extra
#3.

Run it:

```sh
python3 -P -s main.py
```

No third-party packages, no network, deterministic output. The poster text
is rendered from DejaVu Sans Bold glyphs (free license) embedded as bitmaps
in `main.py`; see `tools/make_font.py` for the extraction provenance.
